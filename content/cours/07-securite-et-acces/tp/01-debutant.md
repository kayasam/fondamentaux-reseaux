# TP 07 - NAT et acces securise - Version debutant > Chapitre associé : [[07-securite-et-acces]] ## Objectifs  - Comprendre le role de NAT/PAT - Relier un LAN prive a un reseau externe - Verifier qu'une sortie vers l'exterieur fonctionne  ## Contexte  Un LAN prive `192.168.30.0/24` doit acceder a un serveur externe.  Tu disposes de :  - 1 routeur cote LAN - 1 routeur cote externe - 1 switch - 2 PC internes - 1 serveur web externe  ## Travail demande  ### Partie 1 - Adressage  Utilise le schema suivant :  | Equipement | Adresse | |---|---| | R1 vers externe | 100.100.100.1/30 | | R2 vers R1 | 100.100.100.2/30 | | R2 vers LAN | 192.168.30.254/24 | | Serveur externe | 80.80.80.80/24 | | PC1 | 192.168.30.11/24 | | PC2 | 192.168.30.12/24 |  ### Partie 2 - Routage  1. Configure les interfaces. 2. Ajoute la route par defaut sur le routeur du LAN si necessaire.  ### Partie 3 - NAT/PAT  Sur le routeur cote LAN :  1. declare l'interface interne 2. declare l'interface externe 3. cree une ACL pour le reseau prive 4. active le PAT  ### Partie 4 - Test  1. Teste un ping vers le serveur externe. 2. Verifie les traductions NAT.  ## Commandes utiles  ```text show ip nat translations show ip nat statistics show ip route ```
