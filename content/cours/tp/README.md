# TP - Fondamentaux reseaux

Ce dossier regroupe des TP reorganises pour suivre le cours `formations/fondamentaux-reseaux/cours`.

## Organisation

Chaque TP contient trois fichiers :

- `01-debutant.md` : version guidee, adaptee a une premiere prise en main
- `02-avance.md` : version plus exigeante, avec plus d'autonomie ou de diagnostic
- `03-correction.md` : correction detaillee avec reponses attendues et points de vigilance

## Origine pedagogique

Ces TP reprennent et ameliorent plusieurs travaux existants issus notamment de :

- `Ressources/archive/hd-couche/...` (ancien contenu Dawan)
- `Ressources/archive/tp-unique-ancien.md`

L'objectif n'est pas de recopier les anciens enonces, mais de :

- mieux coller au plan du cours actuel,
- proposer une progression debutant -> avance,
- rendre les corrections exploitables sans formateur,
- uniformiser le format de toutes les activites.
